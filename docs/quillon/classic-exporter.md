# Export productions with the classic exporter

:::warning[Archived]
The classic exporter was retired on 1 August 2026. Use **Productions** in each matter. This page stays for teams answering questions about productions made before that date.
:::

The classic exporter produced load files in DAT and OPT format from a saved search. Productions made with it list **Classic** in the **Exporter** column of the matter's **Productions** page.
