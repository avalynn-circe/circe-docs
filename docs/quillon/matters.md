# Create a matter

A matter holds every document, review set, and production for one case. After this page you can open a matter, set its numbering, and invite the first people to work in it.

## Before you start

You need the **Workspace admin** role. Ask your Quillon administrator if **New matter** does not appear on the **Matters** page.

Have these details ready. The Bates prefix cannot change after the first production.

| Field | Example | Notes |
|---|---|---|
| Matter name | Harlow v. Benton Freight | Shown to everyone with access. |
| Client | Benton Freight LLC | Used for billing exports. |
| Matter number | 2026-0418 | Your firm's internal number. |
| Jurisdiction | D. Minn. | Free text. |
| Bates prefix | BFL | Letters only, 2 to 6 characters. |

## Steps

1. Go to **Matters** and select **New matter**.
2. Enter the matter name, client, matter number, and jurisdiction.
3. Enter the **Bates prefix**. Quillon shows the first number it will assign, for example `BFL000001`.
4. Select **Create matter**. Quillon opens the matter's **Overview** tab.
5. Select **People** and then **Add people**. Choose a role for each person:
    - **Matter admin** manages people, review sets, and productions.
    - **Reviewer** tags and codes documents in assigned review sets.
    - **Viewer** reads documents and work product. Viewers cannot tag.
6. Select **Send invitations**.

## What happens next

Invited people see the matter on their **Matters** page within a minute. To keep specific people out of the matter entirely, set up an [ethical wall](./ethical-walls.md) before you load documents.
