# Governing the Commons: Four Lessons

Four interactive lessons on Elinor Ostrom's work, by Avalynn Circe.

- index.html: landing page that links all four
- lake-wren.html: Saving Lake Wren (eight design principles)
- larkspur-in-layers.html: Larkspur in Layers (polycentric governance)
- kettle-street-fund.html: The Kettle Street Fund (behavioral theory of the individual)
- juniper-falls-charter.html: The Juniper Falls Charter (types of goods and governance)

Each file is self-contained. No build step and no server code are needed.

## GitHub Pages
1. Copy this folder into your repo, for example as a folder named lessons.
2. Commit and push. The page is live at your Pages address followed by /lessons/.

## IONOS or any web host
Upload the folder by FTP or the file manager. Open index.html in the browser.

## Notes
- Fonts load from Google Fonts. Offline, the lessons fall back to system fonts.
- Progress is saved in each visitor's own browser.
